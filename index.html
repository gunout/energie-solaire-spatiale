🧮 Détail complet des calculs satellite (modèle expert UIT)

1. Géométrie orbitale

d = h / sin(θ)

Pour GEO à 90° : d = 35 786 km

2. Constante solaire et puissance captée

P_solar = S₀ × S × η_PV

S₀ = 1 361 W/m² (constante solaire AM0)

Exemple 3 km² × 30 % → 1 224,9 MW

3. FSPL (Free Space Path Loss)

FSPL(dB) = 20·log₁₀(d_km) + 20·log₁₀(f_GHz) + 92,45

GEO, 5,8 GHz : 198,79 dB

4. Pertes atmosphériques

Gaz (ITU-R P.676-13) — modèle 3 raies :

γ_O₂ = 0,00719·P·f²·60² / [(f²+60²)·((f-60)²+15²)]
γ_H₂O = 0,0021·ρ·f²·22,235² / [(f²+22,235²)·((f-22,235)²+4²)]
A_gaz = (γ_O₂ + γ_H₂O) × d / sin(θ)

Pluie (ITU-R P.838-3) :

k = 4,21·10⁻⁵·f^2,42 ; α = 1,41·f^(-0,0779)
γ_R = k·R^α ; A_pluie = γ_R × L_eff / sin(θ)

Nuages (ITU-R P.840) :

K_l = 0,5·(f/10)^1,5 ; A_nuage = K_l × L_nuage / sin(θ)

5. Gains d'antennes paraboliques

G(dBi) = 10·log₁₀(η_A · (πD/λ)²) avec η_A = 0,55

Pour D_Tx = 200 m → 79,1 dBi
Pour D_Rx = 5 km → 107,1 dBi

6. Bilan de liaison

P_rx(dBW) = P_tx(dBW) + G_Tx + G_Rx − FSPL − A_atm

7. Puissance nette et rendement

P_nette = P_rx × η_RF→DC
η_global = P_nette / P_solar

8. Tache de diffraction (Airy)

θ_Airy = 1,22 · λ / D_Tx
D_tache = θ_Airy × d

9. Densité au sol

ρ = P_nette / (π · (D_tache/2)²)

10. Limites ICNIRP

Public : 10 W/m² · Travailleurs : 50 W/m²

⚠️ Le rendement d'un SBSP GEO est structurellement faible (< 2 %) à cause de la distance. Un système LEO atteint 15–20 %.

📈 Marge de liaison vs distance
🧮 Détail complet des calculs drone

1. Distance slant

d_slant = √(h² + D²)

h = 100 m, D = 300 m → 316,2 m

2. FSPL

FSPL = 20·log₁₀(d_km) + 20·log₁₀(f_GHz) + 92,45

97,72 dB pour la config par défaut

3. Gains d'antennes

G_Tx = 10·log₁₀(0,55 · (π×1,5/0,0517)²) = 36,6 dBi
G_Rx = 10·log₁₀(0,55 · (π×0,30/0,0517)²) = 22,6 dBi

4. Bilan de liaison (dBm)

P_tx = 10·log₁₀(2000 × 1000) = 63,01 dBm
P_rx = 63,01 + 36,6 + 22,6 − 97,72 = 24,49 dBm

P_rx = 10^(24,49/10) / 1000 = 0,281 W

5. Marge de liaison

Marge = P_rx(dBm) − 10·log₁₀(P_conso × 1000)
Marge = 24,49 − 51,76 = −27,3 dB
⚠️ Marge négative → le drone ne reçoit pas assez d'énergie !

🧮 Détail des 4 leviers technologiques

Levier 1 — Amplificateur GaN classe F⁻¹

η_F⁻¹ = 1 / (1 + (V_sat/V_dd) × (π/2))

GaN (V_sat=2V, V_dd=28V) → η théorique = 89,9 %
Pratique : 76 %

Levier 2 — Faisceau Flat-Top

Uniformise la densité → évite la saturation de la diode centrale

Rendement transmission : 46,6 % (vs 30 % gaussien)

Levier 3 — Rectenna métasurface + GaAs Schottky

f_c = 1 / (2π · R_s · C_j)

Avec R_s = 5 Ω, C_j = 0,1 pF → f_c ≈ 318 GHz
Rendement RF→DC : 79,5 %

Levier 4 — Signal pulsé à haut PAPR

PAPR_opt = 10·log₁₀(V_br / V_seuil) − 3

PAPR théorique : 15,2 dB · pratique : 9 dB
Rapport cyclique optimal : 30 %

🧮 Détail des calculs LEO vs GEO

1. Période orbitale (Kepler)

T = 2π · √(a³ / μ) avec μ = 3,986×10¹⁴ m³/s²

550 km → 95,6 min

2. Vitesse orbitale

v = √(μ / a) = 7,59 km/s

3. Temps de passage

t_pass = 2 · η · a / v ≈ 363 s

4. Nombre de satellites requis

N = ⌈T / t_pass⌉ = 16

5. Gain FSPL vs GEO

ΔFSPL = 20·log₁₀(35 786 / 550) = 36,3 dB
✅ Le LEO gagne 36 dB → rendement ×4 200 vs GEO

🧮 Détail des calculs laser

1. FSPL optique

FSPL = 20·log₁₀(4πd / λ)

Pour λ = 1064 nm, d = 35 786 km → 293,5 dB

2. Divergence

θ = λ / (π · w₀) avec w₀ = D_Tx / 2

Pour D_Tx = 1 m → 0,68 μrad

3. Tache au sol

D_tache = θ × d = 24,3 m

4. Rendement global

η_global = η_laser × η_transmission × η_PV

Pour GEO : 0,0001 %

⚠️ Laser inefficace pour GEO. Utile uniquement pour LEO ou communications optiques.

1. Profil Cn²(h)

Cn²(h) = 0,00594·(v/27)²·h¹⁰·exp(−h/1000)

r₀ = [0,423 · k² · ∫Cn²(h)·dh]^(−3/5)

θ₀ = [2,91 · k² · ∫Cn²(h)·h^(5/3)·dh]^(−3/5)

📈 Distribution du rendement
🧮 Détail de la simulation Monte-Carlo

1. Principe

x_i = x_nominal × (1 + σ × N(0,1))

Avec Box-Muller :

N(0,1) = √(−2·ln(U₁)) × cos(2π·U₂)

2. Statistiques

μ = (1/N) · Σ η_i
σ = √[(1/N) · Σ (η_i − μ)²]

3. Interprétation

  • μ : rendement attendu
  • σ : dispersion
  • P5 : pessimiste
  • P95 : optimiste

📊 Résumé exécutif — Projet SBSP

Le projet SBSP (Space-Based Solar Power) vise à produire de l'énergie électrique depuis l'espace et à la transmettre vers le sol par faisceau micro-ondes. Non compétitif pour la production terrestre civile, il présente un intérêt stratégique majeur pour les applications militaires, spatiales et isolées.

🧮 Détail des calculs satellite (modèle expert UIT)

1. Distance effective

d = h / sin(θ)

2. Constante solaire ajustée

S₀ = 1361 × (1 + 0,01·(A_sun − 1))

3. Puissance solaire captée

P_solar = S₀ × S × η_PV

4. FSPL

FSPL = 20·log₁₀(d_km) + 20·log₁₀(f_GHz) + 92,45

5. Pertes gaz (ITU-R P.676-13)

γ_O₂ = 0,00719·P·f²·60² / [(f²+60²)·((f−60)²+15²)] γ_H₂O = 0,0021·ρ·f²·22,235² / [(f²+22,235²)·((f−22,235)²+4²)]

6. Pertes pluie (ITU-R P.838-3)

k_H = 4,21·10⁻⁵·f^2,42 ; α_H = 1,41·f^(−0,0779) k_V = 4,09·10⁻⁵·f^2,42 ; α_V = 1,41·f^(−0,0779)

7. Atténuation nuages (ITU-R P.840)

K_l = 0,5·(f/10)^1,5 ; A_nuage = K_l · L / sin(θ)

8. Scintillation (ITU-R P.618)

σ = 3,5·10⁻⁴ · N_wet · f^(7/12) / sin(θ)^1,2

9. Gains antennes

G(dBi) = 10·log₁₀(η_A·(πD/λ)²) avec η_A = 0,55

10. Bilan (dBW)

P_rx(dBW) = P_tx(dBW) + G_Tx + G_Rx − FSPL − A_atm

11. Efficacité interception (Goubau)

τ = π·D_tx·D_rx / (4·λ·d) ; η_int = 1 − exp(−τ²)

12. Tache réelle

D_tache = √(D_Airy² + D_pointage² + D_scint²)

13. Densité au sol

ρ = P_net / (π·(D_tache/2)²)

14. Limites ICNIRP

Public : 10 W/m² · Travailleurs : 50 W/m²

🧮 Détail des calculs LEO vs GEO

1. Période orbitale (Kepler)

T = 2π·√(a³/μ) avec μ = 3,986×10¹⁴ m³/s²

2. Vitesse orbitale

v = √(μ/a)

3. Angle central max

η = arccos(R_T/(R_T+h)·cos(ε_min)) − ε_min

4. Temps de passage

t_pass = 2·η·a/v

5. N satellites requis

N = ⌈T/t_pass⌉

6. Disponibilité

D = N·t_pass/T

7. Gain FSPL

ΔFSPL = 20·log₁₀(d_GEO/d_LEO)

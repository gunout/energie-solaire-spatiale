🧮 Détail des calculs satellite (modèle expert UIT)

1. Distance effective

d = h / sin(θ)

2. Constante solaire ajustée

S₀ = 1361 × (1 + 0,01·(A_sun − 1))

3. Puissance solaire captée

P_solar = S₀ × S × η_PV

4. FSPL

FSPL = 20·log₁₀(d_km) + 20·log₁₀(f_GHz) + 92,45

5. Pertes gaz (ITU-R P.676-13, modèle 3 raies)

γ_O₂ = 0,00719·P·f²·60² / [(f²+60²)·((f−60)²+15²)] γ_H₂O = 0,0021·ρ·f²·22,235² / [(f²+22,235²)·((f−22,235)²+4²)] A_gaz = (γ_O₂ + γ_H₂O) · d / sin(θ)

6. Pertes pluie (ITU-R P.838-3)

k_H = 4,21·10⁻⁵·f^2,42 ; α_H = 1,41·f^(−0,0779) k_V = 4,09·10⁻⁵·f^2,42 ; α_V = 1,41·f^(−0,0779) γ_R = k·R^α ; A_pluie = γ_R · L_eff / sin(θ)

7. Atténuation nuages (ITU-R P.840)

K_l = 0,5·(f/10)^1,5 ; A_nuage = K_l · L_cloud / sin(θ)

8. Scintillation (ITU-R P.618)

σ = 3,5·10⁻⁴ · N_wet · f^(7/12) / sin(θ)^1,2 A_scint = 2σ

9. Gains antennes

G(dBi) = 10·log₁₀(η_A·(πD/λ)²) avec η_A = 0,55

10. Bilan (dBW)

P_rx(dBW) = P_tx(dBW) + G_Tx + G_Rx − FSPL − A_atm

11. Tache réelle

D_tache = √(D_Airy² + D_pointage² + D_scint²)

12. Efficacité interception (Goubau)

τ = π·D_tx·D_rx / (4·λ·d) ; η_int = 1 − exp(−τ²)

13. Densité au sol

ρ = P_net / (π·(D_tache/2)²)

14. Limites ICNIRP

Public : 10 W/m² · Travailleurs : 50 W/m²

🧮 Détail des calculs drone (modèle expert)

1. Distance slant

d = √(h² + D²)

2. FSPL

FSPL = 20·log₁₀(d_km) + 20·log₁₀(f_GHz) + 92,45

3. Modèle Two-Ray (sol + LOS)

Γ = |(sinθ − √(ε_r − cos²θ)) / (sinθ + √(ε_r − cos²θ))| Δφ = 2π·f·(2h·sinθ)/c L_2ray = −20·log₁₀|1 + Γ·e^(jΔφ)|

4. Pertes gaz (ITU-R P.676, altitude)

P = 1013·exp(−h/8500) γ_O₂ + γ_H₂O selon modèle 3 raies

5. Atténuation feuillage (ITU-R P.833)

A_fol = 0,2·f^0,3·d^0,6 · (couvert)

6. Effet Doppler

f_d = f·v/c τ_coh = 1/(2·f_d)

7. Bilan thermique

P_diss = P_rx − P_utile ΔT = P_diss / (h_conv · A_rectenna)

8. Bilan (dBm)

P_rx(dBm) = P_tx(dBm) + G_Tx + G_Rx − FSPL − A_gaz − A_2ray − A_fol − A_vent

9. Durée de vol

t = Capacité_batterie / Consommation

🔬 Conception optimale — Modèle expert MPT

Pour maximiser le rendement d'un système MPT (Microwave Power Transfer) pour drone, la littérature scientifique identifie quatre leviers technologiques qui, combinés, permettent d'atteindre un rendement système de ~25 % (vs 3-5 % pour une configuration classique).

Le simulateur utilise les modèles physiques réels : Woodward-Lawson, diode GaAs Schottky, classe F⁻¹ GaN, PAPR optimal.

1

📡 Faisceau Flat-Top (Woodward-Lawson)

Un faisceau gaussien concentre l'énergie au centre de la rectenna, ce qui sature la diode centrale. Un faisceau Flat-Top maintient une densité uniforme sur toute la surface de la rectenna.

🧮 Méthode Woodward-Lawson

F(θ) = Σₙ aₙ · sinc(π · N · d/λ · (sin θ − sin θₙ))

🧮 Tache au sol

θ_3dB = 1,22 · λ / D_tx ; D_tache = θ_3dB · distance

🧮 Efficacité de transmission

η_Tx = 0,90 · exp(−(D_tache/D_rectenna)²/2) [Flat-Top]
η_Tx = 0,84 · exp(−(D_tache/D_rectenna)²) [Gaussien]
2

📶 Rectenna à métasurface + GaAs Schottky

Une métasurface intègre simultanément la fonction d'antenne, la suppression d'harmoniques et l'adaptation d'impédance directement avec la diode.

ParamètreRectenna classiqueRectenna métasurface
Rendement RF→DC~55 %> 75,6 %
Suppression harmoniquesFiltre externeIntégrée
Masse~500 g / 20 W~200 g / 20 W

🧮 Fréquence de coupure diode

f_c = 1 / (2π · R_s · C_j)

GaAs Schottky (R_s = 5 Ω, C_j = 0,1 pF) → f_c ≈ 318 GHz

3

⚡ Signal pulsé à haut PAPR

Les diodes Schottky sont non-linéaires. Un signal pulsé avec duty cycle optimisé maximise la puissance crête et le rendement.
